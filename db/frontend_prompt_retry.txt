# Gold Fulfillment Retry Flow — Frontend Prompt

## Overview
Level 2 admin can retry gold buy for failed orders directly from the dashboard.

## Flow
```
1. Level 2 admin sees pending request with status "FAILED" or "PENDING"
2. Clicks "Retry Buy" button
3. Dashboard calls POST /api/v1/admin/fulfillment/{id}/retry-buy
4. Dashboard loads buy parameters from the request (lock_price, block_id, metal_type, etc.)
5. Dashboard calls Sabbpegold POST /api/v1/orders/buy/create with these parameters
6. If buy succeeds → status becomes "PROCESSED"
7. If buy fails → status becomes "REJECTED" with error message
8. Retry count is incremented
```


## Frontend UI

### Level 2 Admin Dashboard
1. Show pending requests table
2. Each row shows:
   - Order ID, Customer name, Amount
   - Status badge (PENDING/APPROVED/REJECTED/PROCESSED)
   - Retry count (if > 0)
   - Last retry time (if retried)
3. Action buttons:
   - "Approve" → calls POST /{id}/approve
   - "Reject" → calls POST /{id}/reject
   - "Retry Buy" → calls POST /{id}/retry-buy (only for PENDING/APPROVED status)
   - "Mark Processed" → calls POST /{id}/process (only for APPROVED status)
